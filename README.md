## 🚀 About The Project

**Thenux Fitness** is a premium Android fitness application built for athletes, gym enthusiasts, and beginners who want to stay consistent with their fitness journey.

The application combines modern Android UI, advanced progress tracking, athlete profile management, smart reminders, and beautiful fitness analytics into one powerful, fully offline-capable experience.

> *"Built for those who don't skip leg day — or any day."*

**Why Thenux Fitness?**
- ✅ **Fully offline** — No internet required, all data is stored locally
- ✅ **Multi-athlete support** — Manage multiple profiles on one device  
- ✅ **Beautiful UI** — Material Design 3 with adaptive dark & light themes
- ✅ **Zero ads** — Clean, distraction-free experience
- ✅ **Open Source** — Community-driven and transparent

### 👤 Athlete Profiles

Create and manage **multiple athlete accounts** on a single device. Each profile stores:

| Field | Description |
|-------|-------------|
| 🏷️ **Name** | Athlete display name |
| 📏 **Height** | In cm or feet/inches |
| ⚖️ **Weight** | In kg or lbs |
| 🎂 **Age** | For personalized recommendations |
| 🏋️ **Workout Stats** | Session history and totals |
| 🎯 **Fitness Goals** | Custom targets per athlete |

> All profile data is saved locally using **SQLite** with instant switching between accounts.

## 📂 Installation

### Option 1 — Install APK directly

1. Download the APK from this repository:
   ```
   ./Thenux-fitness.apk
   ```
2. On your Android device, enable **"Install from unknown sources"** in Settings
3. Open the downloaded APK and tap **Install**
4. Launch **Thenux Fitness** and create your athlete profile

### Option 2 — Build from source

**Prerequisites:**
- Android Studio Hedgehog (2023.1.1) or newer
- JDK 17 or higher
- Android SDK 34

```bash
# 1. Clone the repository
git clone https://github.com/thenuxofc/thenux-fitness.git

# 2. Navigate into the project
cd thenux-fitness

# 3. Open in Android Studio
# File → Open → Select the project folder

# 4. Sync Gradle and run on device or emulator
# Click ▶ Run or press Shift+F10
```

> 💡 **Tip:** Use an Android emulator with API 26+ or a physical device running Android 8.0+

## 🤝 Contributing

Contributions are what make the open source community amazing! Any contribution you make is **greatly appreciated**.

### How to Contribute

```
1. 🍴  Fork the repository
2. 🌿  Create your feature branch    →  git checkout -b feature/amazing-feature
3. 💾  Commit your changes           →  git commit -m "feat: add amazing feature"
4. 📤  Push to your branch           →  git push origin feature/amazing-feature
5. 🔁  Open a Pull Request           →  Describe your changes clearly
```

### Commit Message Convention

We follow [Conventional Commits](https://www.conventionalcommits.org/):

| Prefix | When to use |
|--------|------------|
| `feat:` | New feature |
| `fix:` | Bug fix |
| `ui:` | UI/visual changes |
| `docs:` | Documentation update |
| `refactor:` | Code refactoring |
| `test:` | Adding tests |

### Code Style

- Follow [Kotlin coding conventions](https://kotlinlang.org/docs/coding-conventions.html)
- Use meaningful variable and function names
- Add comments for complex logic
